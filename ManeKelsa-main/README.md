# ManeKelsa

ManeKelsa is an Android application designed to connect users with workers for various services. The app utilizes Jetpack Compose for the UI and Firebase Firestore for real-time data synchronization.

## Features

- **Worker Profiles**: View detailed profiles of workers including skills, daily rates, and availability.
- **Real-time Updates**: Real-time synchronization of worker availability and details using Firebase Firestore.
- **Material 3 Design**: A modern, responsive UI built with Jetpack Compose and Material 3.
- **Location Awareness**: Integrated with GeoPoints for location-based services.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Backend**: Firebase Firestore
- **Asynchronous Programming**: Coroutines & Flow
- **Dependency Management**: Gradle Kotlin DSL

## Getting Started

### Prerequisites

- Android Studio Hedgehog or newer.
- A Firebase project with Firestore enabled.
- `google-services.json` file placed in the `app/` directory.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ManeKelsa.git
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical device.
